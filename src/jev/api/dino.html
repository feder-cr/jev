A Chrome Dino-style game made for this demo. Every few frames the game tells the model what the
      next obstacle is and whether it is close, and asks two yes/no questions. The dinosaur jumps or ducks when
      P(yes) > 0.5. The game waits while the model answers; the time per decision is shown above.
